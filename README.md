# Endolaser — Treino (PWA)

App gamificado (estilo Duolingo) para estudar o tratamento com endolaser — baseado no Método Sem Varizes (Dr. José Rosa).
Trilha de lições, questões com explicação, flashcards com repetição espaçada, XP, ofensiva (streak) e progresso.
Conteúdo educacional; não substitui avaliação médica.
